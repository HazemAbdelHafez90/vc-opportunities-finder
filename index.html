      EEAS Tenders

      Public European External Action Service procurement notices. Listings are filtered for visual media and production work.

      SIMAP

      Swiss public procurement notices via the public search API. Review the source notice for authoritative details; Tender Radar's fit and ranking are separate analysis.

      Status: live source

      Fairtrade International tenders and RFPs. Vacancies are excluded from the tender feed.

      Status: live source

      Welthungerhilfe Tenders

      Humanitarian NGO tender page with public listings. This source is now part of the live tender feed and still passes through the same media-focused keyword filter.

      Status: live source now tracked

      Aid-LINK Tenders

      Humanitarian procurement platform focused on aid-agency tenders. Relevant for manual discovery, but the public site is more commercial and harder to scrape cleanly.

      Status: useful manual source

      Open source

      NGOtenders

      Niche NGO and UN opportunity board that can surface procurement notices closer to our humanitarian scope than the broad global tender aggregators.

      Status: useful manual source

      Status: useful manual source
